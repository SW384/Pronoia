# Website Structure
The website uses HTML sections and JavaScript navigation to switch between different pages without loading separate HTML files. CSS is used for styling, layout, responsiveness, and visual effects.
The website features a clean, minimal design with a nature-inspired color palette, including:
- Light neutral backgrounds
- Dark green text
- Muted green accents
- Responsive layouts for desktop and mobile devices
